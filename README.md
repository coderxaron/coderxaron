Potato Bot: 
Potato is a Discord bot that adds potatos to your server. It spawns random potatoes in chat based on activity, and people can grab them by typing !g. Collected potatos are stored in a personal inventory that can be viewed with !inventory, and each server has its own leaderboard you can view it using !potatoleaderboard. The bot also has additional systems like trading, spawn control, and various commands for both users and administrators. You can see all available commands with !help. Website is under development but you can find the Support Server and install link on https://potatobot.netlify.app
